# 检测统计上线

本次更新同时涉及 Vue 前端和 FastAPI 后端，需要重新构建前端并重启 Web 后端。
无需为这次统计调整升级模型引擎 Docker。

后端使用 `web/FastAPI/data/detection_tasks.sqlite3` 保存检测与查询记录。
首次启动新版后端时写入 `live_stats_started_at`，此时间以前的试用记录保留在
SQLite 中，但不再纳入页面统计。此操作仅执行一次；之后重启不会再次清零。
请持久化并备份此数据库，勿在更新时删除它。

统计口径：

- 每个被接收的文件检测请求按任务 ID 计一次，重复通知、结果轮询和刷新不重复累计。
- 累计检测 = 判定恶意 + 未检出恶意 + 其他 / 处理中。
- 页面“未检出恶意”合并 Benign 与未通过 PE 校验的文件；单次检测报告和原始统计中的
  `benign_total` 仍只表示明确的 Benign 结果，PE 校验失败不会生成 Benign 模型判定。
- 失败、取消、未明确判定及未完成的检测归入“其他 / 处理中”。
- SHA256 查询独立统计，每次有效查询增加一次：查询总数 = 命中 + 未命中 + 失败。
  查询不增加文件上传检测次数，重复查询同一个哈希仍是新的一次查询。
- 样本库命中、模型检测完成、SHA256 去重数量是不同维度，不应相加作为累计检测。

部署后请求 `/detection-stats`，应返回 `available: true`、新的 `started_at`，以及
`not_detected_total`、`other_total` 字段。没有新请求时所有数量应为零。
